# AI Agent 三段式布局设计

## 概述

为 doc-format-platform 添加 AI Agent 功能，采用三段式布局：左侧 AI 聊天 → 中间配置面板 → 右侧格式预览。

## 布局方案

### 三列布局（桌面端）

```
┌──────────┬──────────────────┬───────────────────────────┐
│ AI Chat  │  配置面板         │  格式预览                  │
│          │                  │                           │
│  可折叠   │                  │                           │
│  可拖拽   │                  │                           │
│          │                  │                           │
│ ════════ │ ═══════════════ │ ═════════════════════════ │
│ (拖拽手柄)│  (拖拽手柄)       │                           │
└──────────┴──────────────────┴───────────────────────────┘
```

### 宽度方案

- **左侧聊天面板**：可折叠 + 可拖拽。展开时默认 360px，用户自由拖到任意宽度，拖过 200px 自动折叠
- **中间配置面板**：最小 280px，可拖拽调整
- **右侧预览**：弹性占满剩余空间，最小 400px

左侧聊天面板折叠后，中间和预览按黄金比例重新分配。

### 移动端适配

窄屏（< 900px）时自动堆叠：
- 聊天面板折叠为底部浮窗按钮，点击弹出
- 配置面板和预览上下排列

## 组件架构

### 新增文件

```
src/
  app/
    page.tsx              # 改造为三段式布局
  components/
    layout/
      ThreePanelLayout.tsx   # 三列布局容器
      PanelToggle.tsx        # 聊天面板折叠按钮
    chat/
      ChatPanel.tsx          # AI 聊天面板
      ChatMessage.tsx        # 单条消息
      ChatInput.tsx          # 消息输入框
      ChatHistory.tsx        # 历史记录列表
```

### 依赖

- `react-resizable-panels` — 可拖拽面板

## AI 聊天功能

### 核心能力

用户通过自然语言描述排版需求，AI 理解后自动填充配置面板或直接调用 Python 引擎格式化。

### 第一期范围

1. 用户输入自然语言描述（如"排成学术论文格式"）
2. AI 解析需求，输出配置参数
3. 配置自动填充到中间面板，用户可手动微调
4. 显示格式化结果到右侧预览

### 多轮对话

- 保留对话历史上下文
- 支持追问和调整（"标题再大一点"）
- 每条消息显示 AI 思考/处理状态

## 实现步骤

1. 安装 `react-resizable-panels` 依赖
2. 创建 `ThreePanelLayout` 三列布局容器
3. 改造 `page.tsx` 为三段式布局
4. 实现聊天面板 UI（折叠/展开/拖拽）
5. 实现 AI 聊天功能（消息列表、输入框）
6. 集成现有配置面板和预览
7. 移动端适配

## 边界情况

- 聊天面板折叠时，AI 功能通过浮动按钮触发
- 预览内容为空时显示"等待格式化"占位
- 拖拽面板时内容实时适配，不闪烁
- 宽度设置持久化到 localStorage
